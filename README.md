# pfetch.el

A GNU Emacs package made to learn how to extend GNU Emacs.

# Installing

```emacs-lisp
(use-package pfetch-el
  :ensure t
  :vc "https://github.com/loureir-or-not/pfetch.el")
```

# Usage

Run `M-x pfetch`. If you want more than one pfetch, run
`C-u 0 M-x pfetch` with `0` being any number you wish.
